# MarinhoLab ROS images

Base `ros` images used in MarinhoLab. Main use case is to serve as base images for
[`sas`](https://github.com/SmartArmStack/smart_arm_stack_ROS2) builds.

## Overview

| `ros`     | `dqrobotics`                            | `ubuntu`          |
|-----------|-----------------------------------------|-------------------|
| `lyrical` | `ghcr.io/dqrobotics/container:noble`    | `ubuntu:noble`    |
| `jazzy`   | `ghcr.io/dqrobotics/container:resolute` | `ubuntu:resolute` |

## Base images

All base images listed for trackability.
